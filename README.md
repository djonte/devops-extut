# Container Security with Checkov

An interactive Killercoda tutorial about Dockerfile security. It uses Checkov to find configuration problems and Docker to demonstrate their runtime effects.

[Start the tutorial](https://killercoda.com/djonte/scenario/container-security-checkov).

## What you will do

1. Scan an insecure Dockerfile.
2. Run the insecure container and inspect its behavior.
3. Fix the Dockerfile.
4. Rescan and rebuild the image.
5. Verify the container's user, permissions, and health status.

The scenario files are in [`container-security-checkov/`](container-security-checkov/). The original assignment is in [`PROPOSAL.md`](PROPOSAL.md).
